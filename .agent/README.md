# Agent OS

## Mục tiêu

Bộ quy tắc vận hành dự án theo hướng artifact-first, có PM điều phối, QA kiểm chứng và khách hàng nghiệm thu giao diện/chức năng.

## Thứ tự ưu tiên

1. `roles/project-manager.md` điều phối và quyết định trạng thái task.
2. `rules/` quy định cách làm việc.
3. `skills/` mô tả năng lực chuyên môn.
4. `workflows/` mô tả quy trình thực thi.
5. `.manager/` là nguồn sự thật về trạng thái dự án; `.feedback/` là kênh trao đổi Codex–Antigravity.

## Vai trò

- Project Manager: người đứng đầu dự án, nhận task, chia nhỏ, theo dõi tiến độ, duyệt handoff.
- Product Owner: làm rõ nhu cầu, acceptance criteria và phạm vi.
- Developer/Producer: triển khai.
- QA Reviewer: kiểm thử và ghi nhận rủi ro.
- Customer Reviewer: đánh giá UI, user flow và chức năng từ góc nhìn khách hàng.

Mọi task đáng kể phải đi qua: intake → requirements → implementation → QA → customer review → final report.
