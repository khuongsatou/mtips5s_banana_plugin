# Workflow 03: Customer UI & Function Review

1. Đọc acceptance criteria và xác định happy path.
2. Kiểm tra desktop/mobile nếu có thể, text fit, loading, empty, error và thao tác chính.
3. Ghi finding theo mức độ, bằng chứng, expected/actual và đề xuất.
4. Kết luận Accept/Need Changes/Reject; nếu cần sửa, tạo feedback ID và action plan.
