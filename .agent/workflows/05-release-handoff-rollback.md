# Workflow 05: Release, Handoff & Rollback

1. QA xác nhận gate và artifact/report mới nhất.
2. PM kiểm tra scope, feedback mở, manual steps và residual risk.
3. Handoff kèm release notes, cách verify và rollback plan.
4. Nếu phát hiện regression, chuyển Blocked/Need Changes, bảo toàn bản cũ và rollback theo kế hoạch.
