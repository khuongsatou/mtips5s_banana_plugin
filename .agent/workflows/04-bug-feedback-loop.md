# Workflow 04: Bug & Feedback Loop

1. Ghi feedback vào `.feedback/inbox.md`.
2. PM/Developer đánh giá và phản hồi trong `responses.md` với Accept/Reject/Need More Info.
3. Việc được chấp nhận chuyển thành action plan có owner, priority, ETA, status.
4. Sửa → QA verify → cập nhật response log, iteration log và đóng entry khi Done.
