# Workflow 01: PM Task Intake

1. PM đọc yêu cầu và ghi mục tiêu, value, owner, status vào `.manager/current_task.md`.
2. PO tách Must/Should/Could/Out of Scope trong `requirements.md`.
3. PM bổ sung acceptance criteria, rủi ro, next step và ghi `iteration_log.md`.
4. Chỉ bắt đầu implementation khi scope đủ rõ hoặc câu hỏi mở đã được ghi nhận.
