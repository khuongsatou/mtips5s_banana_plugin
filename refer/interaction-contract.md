# Interaction Contract

Lifecycle: checked → connected → input_staged → configured → confirmed → running → completed → qc_passed → delivered.

Lỗi: offline, missing extension, missing flow key, invalid input, confirmation required, failed, cancelled.

Không coi yêu cầu ban đầu là confirmation cuối; mọi thay đổi config phải hiển thị lại card và xin xác nhận.
