# QA & Handoff

Kiểm tra HTTP/JSON response, output path hoặc URL, file tồn tại/đọc được, mime type, kích thước, metadata và preview nếu có. Với media dài, kiểm tra đầu/giữa/cuối; với UI/function, kiểm tra happy path, loading, empty, error và responsive.

Ghi kết quả theo Pass/Fail, residual risk, manual steps và artifact path. Task ảnh hưởng UI/chức năng phải có Customer Reviewer kết luận Accept/Need Changes/Reject. Chỉ bàn giao khi terminal state và QC đạt.
